# Evals: Align the site to the owner's master copy

Change id: `2026-10-08-align-the-site-to-the-owner-s-master-copy`
Spec: [spec.md](./spec.md)

Evals turn "does it work" into evidence. Each case is executable where the stack allows it and
becomes a permanent test. Targets are numbers. "The document" is `PORTFOLIO_FIX_MASTER.md`; "the
routes" are the seven paths `sitePagePaths()` returns (`/`, `/work`, five `/work/<id>`), rendered
in process through `src/entry-server.jsx` `render` and `assemblePage`, the way
`src/prerenderIntegration.test.js` already does, so no build is needed inside `npm test`.

## Targets

| Category | Target | Rationale |
|----------|--------|-----------|
| Golden | 100% pass | The owner's strings, word for word, on the data and on every served route |
| Edge | 100% pass | Scanner boundaries: the bans fire on every form and stay silent on the near-misses |
| Failure | 100% correct handling | A reintroduced claim or a lost pin is red, never green |
| Adversarial | 100% rejected | Case and whitespace evasions of the bans still hit |
| Non-functional | see rows | Suite, build, lint, audit, floor and scan time |

## Side effects and records

None: this change writes only tracked source, test and documentation files inside the
repository. The site has no backend, no database, no outbound call and no stored record; the
scanner and the prerender read files and print, and the only publishing act (a push to `main`)
is the owner's own, outside this change's code (`.workhorse/profile.yml` `environments.prod`,
R15). No approval, authorization or idempotency record is read or written by the code.

## Failure taxonomy

| Class | Description | Detection | Example |
|-------|-------------|-----------|---------|
| Wrong result | A pinned string drifts from the document or the resume | the data tests (E1 to E9, E17) and route tests (E12 to E16) go red in `npm test` and in CI's test step | a builder writes "wasn't" where the document says "was not" |
| Leaked | A banned or disclosure string reaches `src/` or a served page | real-tree scan (E23), dist scan (E24), route test (E15); CI fails before publish | "(via TCS)" put back in an eyebrow (E25) |
| Missing result | A cross-reference sentence is absent, duplicated or on the wrong page | E13 | the integration paragraph pasted onto the decision page too |
| Stale artifact | `public/og.png` still shows "Tickets decided a day" after `og.svg` changes | not machine-detectable; the ship document records the `public/og.png` commit (brief D13) | the owner merges before the re-render |
| False green | A pinned suite is deleted or skipped, or the scanner scans nothing | `scripts/check-test-floor.mjs` (E26); scanner exit 2 on an empty scope (existing case) | the renamed test file is not discovered by Vitest |
| Unrecoverable | none | every edit is a tracked file; `git revert` restores the previous copy and GitHub Pages republishes on the next push | not applicable |
