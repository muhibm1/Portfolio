# Evals: rebuild the portfolio to the approved redesign

Change id: `2026-09-25-rebuild-portfolio-to-approved-redesign`
Spec: [spec.md](./spec.md)

Evals turn "does it work" into evidence. Each case is executable where the stack allows it and
becomes a permanent test. Targets are numbers. Test layout: Vitest files under `src/` next to
the component (`*.test.jsx`) or at `src/<topic>.test.js` for scripts and files, run by
`npm test`; scripts are spawned the way CI runs them (`src/checkRoutePages.test.js` pattern).
Manual rows (M) are run by the owner or the main session and recorded in `ship.md`; the verifier
lists them under "Not verified", never counts them as passes. Forty rows, the tier-2 limit.

## Targets

| Category | Target | Rationale |
|----------|--------|-----------|
| Golden | 100% pass | The copy, order and links the outcome depends on |
| Edge | 100% pass | Trailing slash, hash links, word boundaries, hydration parity |
| Failure | 100% correct handling | Prerender and scanners fail closed, never green on nothing |
| Adversarial | 100% rejected | Head-tag escaping, path escape at build |
| Non-functional | see rows | Build time, scan time, test counts, Lighthouse |

## Failure taxonomy

| Class | Description | Detection | Example |
|-------|-------------|-----------|---------|
| Wrong result | Copy, number or order differs from the plan or mockups | G6, G10, G14; M4 by the owner | A stat rounded, a role out of order |
| Missing result | A page, tag, file or link absent | G16, G18, G19, G24, deploy smoke R143 | `og.png` not committed; a route page without its canonical |
| Leaked | A removed claim, dash or internal name reaches the site; a phone number in the PDF | R129 scanner in `npm test` and CI; M5 | "simulator" back in a heading |
| Corrupted | Server and client markup disagree; a block type unknown | E1, G17, the data block-type test | A component reading `window` at render |
| Unrecoverable at build | Prerender or a check passes on nothing | F1, F2, G19 exit-2 rows | Missing `dist/` read as clean |
| Slow | Build or checks exceed their budgets | N1, N3 | A second SSR build doubling build time |
| Unauthorised | Not applicable: no auth surface; the only privileged act is the push to `main`, which the bash guard blocks for agents | profile, R150 | |
