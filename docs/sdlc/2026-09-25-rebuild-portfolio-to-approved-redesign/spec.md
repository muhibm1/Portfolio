### Interfaces

(a) `pageMetaFor(pathname) -> { title, description, canonical | null, ogImage, robots?: 'noindex' }`. Titles: `/` "Muhammad Muhibullah, Forward Deployed Engineer"; `/work` "Case studies | Muhammad Muhibullah"; a slug "<case-study title> | Muhammad Muhibullah"; other "Page not found | Muhammad Muhibullah". Descriptions: the hero lead, the case-studies intro paragraph, the case study's lead, "There is no page at this address." `canonical` is `SITE_URL` joined to the path with a trailing slash. `headTags(meta) -> string` escapes `&`, `<`, `>` and `"` in every value.

(b) `render(url: string) -> string` in `src/entry-server.jsx`; `url` is the full pathname including the basename.

(c) `assemblePage(shellHtml, { headHtml, appHtml }) -> string`: replaces the single `<title>` and description meta, inserts `headHtml` before `</head>`, puts `appHtml` inside `<div id="root">`; throws naming the missing piece if the shell lacks any of the three. `writePage(outDir, pagePath, html) -> relativePath` keeps the outside-`outDir` refusal and the slug rule of 2026-09-21 (R117, R118).

(d) `node scripts/prerender.mjs`: reads `dist/index.html` once, imports `dist-ssr/entry-server.js`, writes the pages in (c), prints `Prerendered <n> pages`, exits 1 with `::error::Prerender failed: <reason>` before writing anything on any error.

(e) `node scripts/check-forbidden-copy.mjs [dist]` and `node scripts/check-route-pages.mjs [dir]`: exit codes and line formats as R129 and R142; `Forbidden copy check passed (R129): <n> files scanned.` and `Route page check passed (R142): <n> pages carry their markers.` on success.

(f) Case-study block shapes (ADR 0006): `{type:'paragraph', text}`, `{type:'bullets', items}`, `{type:'flow', columns, steps:[{title, note, gate?, dashed?}]}`, `{type:'cards', items}`, `{type:'stats', items:[{value, label}]}`, `{type:'table', columns:[{label, numeric?}], rows:[{cells, emphasis?}]}`, `{type:'link-diagram', left, edge, hub, right:[...]}`, `{type:'split', table, stats}`. An unknown `type` throws a readable error at render.

(g) Workflow steps: build job gains `- name: Copy carries no removed claim (R129)` / `run: "node scripts/check-forbidden-copy.mjs dist"` after the route-page check; the deep-link and unknown-path smoke keeps its step name with the new assertions; a new step `"Smoke R143: the resume PDF and the share image are served"` fetches both.

### Security and privacy

- No visitor data, cookie, storage, analytics or third-party origin is added; fonts stay self-hosted (ADR 0002); the CSP is unchanged and every prerendered page carries it (R142). Prerender adds no inline script; because the pages are no longer byte-identical, R142 checks the R82 privacy markers on every page at build and the smoke repeats the R82 counts on the deep-link and 404 bodies (D15).
- Prerendering puts the owner's email address into the served HTML of every page as plain text, readable without JavaScript; today it is only in the JS bundle (believed, not verified). Publishing it is the owner's deliberate choice (plan section 4, D8) and the change in exposure is recorded in `retention_notes` and `hosted-config.md` (R145).
- Head tag injection: every value comes from the data module, never from a request, and is escaped anyway (R139, adversarial case A1). Canonical and `og:url` are built from a constant origin.
- Filesystem writes at build stay behind the slug rule and the outside-`outDir` guard of 2026-09-21 (R117, R118 retained).
- The resume PDF is the owner's own personal data, published deliberately like the email; the owner runs the D12 and D17 checks before adding it (contact fields, phone, street address, document metadata, backlog wording), because the R89 scanner cannot read compressed PDF streams and, after D16, skips `.pdf` by design.
- The workflow's permission blocks do not change; the new steps use `run:` only.

### Failure modes

| Dependency or input | Slow, down or wrong | Handling |
|---|---|---|
| `dist-ssr/entry-server.js` missing or throws | Prerender exits 1 before writing; `npm run build` fails | Nothing stale is uploaded; the check would exit 2 on a missing `dist/` anyway |
| A component reads `window` during render | Server render throws | Build fails naming the component; the entry-server test catches it before CI |
| Server and client markup differ | React logs a hydration error and re-renders on the client | The hydration test fails on any `console.error` |
| A block `type` is misspelled in the data | Template throws | Data test checks every block type against the fixed set |
| `og.png` or the PDF missing | Test red; build proceeds; smoke fails after merge | Fail closed in CI; recorded as the D2/D4 blocker until supplied |
| A forbidden term returns in copy | Scanner exits 1 | `npm test` locally, the build job in CI |
| Pages redirects `/work/x` to `/work/x/` | 301 then 200 | Smoke follows two redirects as before (2026-09-21 ADR 0003) |
| Fontsource package unavailable at install | `npm ci` fails | Same as any dependency; nothing partial ships |

### Observability

Build log: `Prerendered <n> pages`, the two check scripts' pass lines; CI: each smoke step's status and URL. No production telemetry by design; a broken page is seen by a person, and `docs/hosted-config.md` section 6 lists what to look at after each deploy.
